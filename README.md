# 课前准备

这是一份面向零基础新生的 C++ 前置学习资料。默认你此前没有接触过 C++，请按照本文档的顺序从易到难学习。

- **必修内容**：必须完成，覆盖 C++ 最基本的语法，是后续新培课程的基础。
- **拓展内容**：不强制完成。新培课程会系统讲解 C++ 的 OOP（面向对象）和 CMake，相关文档可以在课前浏览，也可以课后回来学习。

建议边看文档边动手敲代码，不要只看不写。每篇文档中的示例和练习都尽量自己完成一遍。

## 学习建议

1. **先读文档，再敲代码**：看懂每一段代码的作用，不要直接复制粘贴。
2. **动手改一改**：修改变量值、条件、循环次数，观察输出变化。
3. **完成课后练习**：文档中的练习是检验掌握程度的最好方式。
4. **允许暂时不懂**：遇到内存、编译、链接等较深的内容，先记住结论，后续课程会逐步展开。
5. **按顺序学习**：后面的内容依赖前面的知识，尽量不要跳着看；拓展内容可以最后再看。

完成全部必修内容后，你应该能够：

- 定义变量并使用基本数据类型
- 使用运算符和条件、循环语句编写简单逻辑
- 理解作用域，能编写和调用函数
- 理解引用、指针和 `const` 的基本用法
- 使用结构体组织数据
- 使用 `std::string` 处理字符串
